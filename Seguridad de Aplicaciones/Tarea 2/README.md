# Tarea 2: Modelo de amenazas de ParaBank (OWASP Threat Dragon)

| Archivo | Contenido |
|---|---|
| `01-Informe-Modelo-Amenazas.md` | Informe completo: arquitectura, DFD, STRIDE, riesgos, casos de abuso, controles, matriz de remediación y roadmap |
| `02-Threat-Dragon/parabank-threat-model.json` | Modelo para importar en Threat Dragon (3 diagramas, 23 amenazas) |

## Qué te falta hacer
1. Abrir Threat Dragon (versión de escritorio) e importar el JSON. Revisar que los tres diagramas, las fronteras y las amenazas se vean bien; puede ser necesario reacomodar elementos.
2. Tomar capturas de los DFD niveles 0, 1 y 2 y exportar el reporte PDF de la herramienta.
3. Reescribir el informe con tus palabras y completar nombre, carnet y el enlace al repositorio.
4. Validar las hipótesis con Arquitectura/Desarrollo (o dejarlas marcadas como supuestos).
5. Exportar el informe a PDF y subir a Canvas el PDF y el JSON como archivos.

## Fuente
Análisis basado en el código público de ParaBank (https://github.com/parasoft/parabank, commit 13cc8d4c). Es una aplicación vulnerable a propósito, hecha para pruebas.
